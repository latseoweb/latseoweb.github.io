Built-in SEO

Why SEO belongs in the development stage

A website's structure, addresses and headings are cheapest to get right from the start. If they are changed after launch, Google has to re-index the pages, and old links can lead to an error page.

I have experienced this myself. Once, after a URL structure change, Google Ads sent people to a 404 page for four days, and the money paid for those clicks was spent without a single customer. Since then I plan every website so that its addresses and structure will not need to change.

Included in every website

  • Technically clean code and fast loading — the Core Web Vitals metrics Google uses to evaluate pages.
  • Mobile version — the website is adapted for phones and tablets.
  • Clear URL structure — addresses that match the page content.
  • Correct heading hierarchy — one H1 on each page and logical subheadings.
  • SSL certificate — a secure connection (https) in all packages.

If you want to actively grow your rankings after launch, monthly SEO costs from €300/month.
