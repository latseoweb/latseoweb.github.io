Built-in SEO

What built-in SEO includes

I build every website so that Google can read it easily and show it in search.

  • Technically clean code and fast loading — Core Web Vitals metrics
  • Mobile version for phones and tablets
  • Clear URL structure — addresses match the page content
  • Correct heading hierarchy — one H1 on each page
  • SSL certificate — a secure connection in all packages

Active work on rankings after launch — monthly SEO from €300/month.

Frequently asked questions

Questions about website development

How long does it take to build a website?

I build a one-page website in 3–5 working days and a business website in 2–4 weeks. The timeline for an online store depends on the number of products and the functionality, and we agree on it before work starts. The timeline also depends on how quickly the content — texts and images — is ready.

What does built-in SEO include?

Technically clean code and fast loading (Core Web Vitals), adaptation for mobile devices, a clear URL structure, correct heading hierarchy and an SSL certificate.

Which platforms do you use?

WordPress, Shopify, Wix or custom code (HTML, CSS, JavaScript). We choose the platform based on whether you want to edit the content yourself.

Will I be able to edit the content myself after development?

Yes, if the website is built with WordPress, Shopify or Wix. For custom-coded websites, I make the changes at €25 per hour.

Who owns the website?

You own the code and the domain. I provide hosting and maintenance: €10/month for a website, €15/month for an online store.

Do prices include VAT?

No, all prices are excl. VAT.

Can you redesign an existing website?

Yes. I recommend starting with a free video audit — request a free video audit and you will see what is holding your current website back on Google, so you can decide whether to fix it or build a new one.

What happens after launch?

The website keeps running on my hosting, and I take care of maintenance. If you want to actively grow your rankings on Google, I offer monthly SEO from €300/month.
