# Mājaslapu izstrāde — oriģinālās cenas

Šis fails dokumentē mājaslapu izstrādes **standarta cenas** (pirms akcijas).

Akcija ir spēkā **līdz 13.09.2026 23:59** un tiek piemērota automātiski ar JavaScript
failā `majaslapas-izstrade/index.html` (skat. `PROMO_END_DATE` un `promoPackagePrices`).

Pēc 13.09 cenas automātiski atgriežas pie šeit norādītajām — nekādas darbības nav vajadzīgas.
Lai atgrieztu cenas ātrāk, mainiet `PROMO_END_DATE` uz pagātnes datumu vai izdzēsiet
`if (promoActive) { ... }` bloku kalkulatora JavaScript daļā.
